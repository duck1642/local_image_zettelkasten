# Local Image Zettelkasten

Local media ingestion, duplicate detection, vault generation, and PySide6-based management UI.

## Commands

- `python main.py` runs the ingestion pipeline.
- `python gui.py` starts the PySide6 UI.
- `python tools/maintenance/clear_pycache.py` removes Python cache folders.
- `liz` runs the ingestion pipeline.
- `liz-gui` starts the PySide6 UI.

Runtime data lives under `data/`, logs under `logs/`, and credentials under `secrets/`.
